🔧 一键清除登录状态

使用说明：
1. 点击下方按钮清除所有登录状态
2. 页面会自动跳转到登录页
3. 使用新的验证码重新登录
✅ 成功！正在跳转到登录页...
❌ 清除失败，请手动操作

📋 手动清除方法（如果按钮无效）

  1. 按 F12 打开开发者工具
  2. 点击 Application 标签
  3. 左侧找到 Cookies → http://localhost:5000
  4. 找到名为 session 的cookie → 点击删除
  5. 刷新页面 (F5)
  6. 重新登录

🚀 最简单方法：无痕模式

  1. 按 Ctrl+Shift+N 打开无痕窗口
  2. 访问 http://localhost:5000
  3. 全新登录（不会有旧cookie干扰）
